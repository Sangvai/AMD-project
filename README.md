# AMD-project
FitApp – Smart Fitness Tracking Web Application

# Description

FitApp is a modern, browser-based fitness tracking web application designed to help users monitor their daily health activities in a simple and interactive way. The application allows users to track important fitness parameters such as hydration, physical activity (steps), calorie intake, and Body Mass Index (BMI) through a clean and responsive interface.

The application is built using React via CDN and runs directly in the browser without requiring Node.js or any backend setup. It uses local storage to save user data, ensuring that all progress is retained even after refreshing the page.

# Features
User Profile Management (Name, Age, Height, Weight)
Automatic BMI Calculator with health status classification
Hydration Tracker for daily water intake
Step Tracker for monitoring activity
Calorie Tracker for nutrition tracking
Progress bars for goal visualization
Local storage support for persistent data
Responsive design for mobile and desktop
Clean and modern card-based UI

# Technologies Used
HTML5
CSS3
JavaScript (ES6)
React (via CDN)
Babel (for JSX transformation)
LocalStorage API

# How to Run
